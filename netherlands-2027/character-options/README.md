# Character style options (2D redesign)

`character-style-options.png` — the same young Ghanaian presenter (early 20s, low fade with a sharp line-up, orange overshirt
over a cream tee, navy trousers) in three 2D treatments. Rebuild with `node character-options/build.mjs`.

- **A — Polished editorial:** no outlines, shaded planes on face and clothes, soft grain, deep background.
- **B — Playful cartoon hybrid:** ink outline, cel shading, larger eyes and head, cheek colour.
- **C — Simple vector:** flat shapes, dot eyes, a single neck shadow.

These are hand-built vectors (no AI image generation), so the approved option becomes the animation rig directly and the face
stays identical across every expression. The first video draft (`preview/netherlands-2027-draft-v1.mp4`) is untouched for comparison.
